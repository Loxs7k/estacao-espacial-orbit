# Missao Espacial: Estacao Orbital

Projeto desenvolvido para a atividade pratica de Git/GitHub da disciplina de Garantia da Qualidade de Software (Una), simulando o fluxo de desenvolvimento corporativo em tres camadas.

# Camadas do ambiente

- **develop**: branch de desenvolvimento, onde novas funcionalidades sao implementadas.
- **stage**: branch de homologacao/testes, onde as alteracoes sao validadas antes de ir para producao.
- **main**: branch de producao, contendo a versao estavel e final do codigo.

# Modulo

O sistema implementa o **Modulo de Suporte de Vida** (`SuporteVida.java`), responsavel por monitorar os niveis do ambiente da estacao (oxigenio, pressao e sistemas de reciclagem de agua).
